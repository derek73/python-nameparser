# T5 — the written shape of an initial

T5. Rationale: one letter standing for a name word is how an
    initial is written, and the writing marks it: by a period after
    the letter, where the script abbreviates that way, or, in Latin
    script, by a plain capital standing alone.
    A one-letter word written with its period is an initial, in a
    script that writes initials, and so is a bare unaccented Latin
    capital, A to Z. A bare capital of any other letter — an accented
    Latin one, a Cyrillic or Greek one — is not that shape and is a
    name word; written with its period it is an initial like any
    other. Every rule that reads an initial differently from a name
    word reads this shape; a bare lower-case letter is T4's question.
      "J. née Smith"              →  given="J."
      "J née Smith"               →  given="J"
      "Ж. née Smith"              →  given="Ж."
      "Ж née Smith"               →  family="Ж"  · boundary
      "É née Smith"               →  family="É"  · boundary
    Signal: a shape: a one-letter word's period, or a bare unaccented Latin capital
