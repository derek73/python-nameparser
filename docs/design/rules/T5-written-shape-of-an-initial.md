# T5 — the written shape of an initial

**When:** a word of one letter stands in a name, as in "J. née Smith".

**Then:** a one-letter word written with its period is an initial, in a script that writes initials, and so is a bare unaccented Latin capital, A to Z.

- **A bare capital of any other letter** — an accented Latin one, a Cyrillic or Greek one — is not that shape and is a name word; written with its period it is an initial like any other.
  ```
  "Ж. née Smith"              →  given="Ж."
  "Ж née Smith"               →  family="Ж"  · boundary
  "É née Smith"               →  family="É"  · boundary
  ```
- **Every rule that reads an initial differently from a name word reads this shape**, M4, O5, P7, C9, S10 and H2 among them; a bare lower-case letter is T4's question.

**Because:** one letter standing for a name word is how an initial is written, and the writing marks it: by a period after the letter, where the script abbreviates that way, or, in Latin script, by a plain capital standing alone.

```
"J. née Smith"              →  given="J."
"J née Smith"               →  given="J"
```

**Accepted:**

- The period test reads one word character rather than one letter, as v1's did, so a digit written with its period is an initial too. Nobody writes a digit as an initial, so the shape it reaches is not one names take.
  ```
  "1. née Smith"              →  given="1."
  ```

---
**Signal:** shape: a one-letter word's period, or a bare unaccented Latin capital
