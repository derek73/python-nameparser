# script-properties — one private table of what a script's writing does (#1256)

## Standing

- Whether a script has case for the name-case contrast, whether it writes initials, whether it writes period abbreviations and whether a bare run of its letters with a period is a spelled Latin initial are answered by one private table, `_policy._SCRIPT_PROPERTIES`, one row per script with its reason and source, and every rule that asks reads it — 2026-11-12 #1256, the table.
- The rows are keyed by a private name, never by the public `Script` enum, whose membership says what a caller can key a setting on and settles nothing about case or initials — 2026-11-12 #1256, the table.
- "Writes initials" (rules/T5's veto, rules/R7's `initials()`, the name match) and "writes period abbreviations" (rules/H2's shape) are two columns, which the four East Asian rows answer alike — 2026-11-12 #1256, the table.
- Whether a script writes initials is decided by its convention, read where CLDR states one from the locale-authored name patterns that produce an initial, after checking that the locale's block is not a copy of `en`'s — 2026-11-12 #1256, the table.
- The answers the fixes for #1191 (the Brahmic title-shape veto), #1214, #1223 and #1224 (case repair) gave are rows, not reopened; the Dutch `IJ` (#1242) is a language question and has no row — 2026-11-12 #1256, the table.
- Georgian, Mkhedruli and Mtavruli (U+10D0–10FF, U+1C90–1CBF), has no case for the name-case contrast, read alike by the parse's one-case fact (decisions/S6), the credential lean and the case-repair gate (decisions/R5), and rules/R4's repair writes its first letter in its lower case from the same row; the ecclesiastical Asomtavruli and Nuskhuri, which write initial capitals, are not in the row — 2026-11-12 #1222.
- The Myanmar script writes no initials, decided on #1234 from the Burmese convention rather than from CLDR, whose `my` block is `en`'s copied; whether it writes period abbreviations is not decided and reads as before — 2026-11-12 #1234.
- The Thai script writes no initials, by CLDR's recipe (`th` 0 of 20), and writes period abbreviations, so its titles written short read as before — 2026-11-12 #1256, Thai.

Open: none in this file.
