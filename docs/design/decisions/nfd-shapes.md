# nfd-shapes — shape tests read letters, and a decomposed letter is one letter

## Standing

- A letter in the letter-shape regexes is `_vocab._LETTER` (a letter plus the general combining blocks), and the caps predicates compose a word not already NFC before `isalpha()` and count letters with `composed_len`, so a name typed decomposed reads as its composed twin and keeps the encoding written: decomposed `Dr. inž. Janez Novak` → title 'Dr. inž.', `Janez Novak, ŽŠČ` → suffix 'ŽŠČ', `Janez Novak, Ž.Š.` → given names 'Ž.Š.', family 'Janez Novak' — 2026-10-12 #652.
- The class is not widened to every script's marks (Indic vowel signs, Arabic and Hebrew points), rules/H2's Accepted clause recording that an abugida abbreviation never reads as a title by shape (for one written with a vowel sign; the ten Brahmic scripts from Devanagari to Sinhala are kept from the shape by script since 2026-11-08 #1191, decisions/H2) — 2026-10-12 #652.
- The initial shape and the #320 script veto are asked of the composed spelling and the single-letter width tests count composed letters, the public v1 `initial` regex left as written: decomposed `É. y É. Smith` → given 'É.', middle 'y É.', `John й Smith` → given 'John', middle 'й', family 'Smith', `김. 민준` → family '김.', given '민준', and `김민준, 씨.` → suffix '씨.'; a connective with no precomposed form is two letters (`q́` added to `conjunctions` reads `John q́ Smith` as given 'John q́ Smith') — 2026-10-13 #665.
- An unspaced decomposed hangul name is still not divided, so `김민준. 이서연` reads by encoding (decomposed: family '김민준.', given '이서연') — 2026-10-13 #665.
- The script table's HANGUL holds the conjoining jamo (U+1100–11FF, U+A960–A97F, U+D7B0–D7FF) beside the precomposed syllables, so a reader of raw characters sees a decomposed syllable as hangul: decomposed `이서연·김민준` → given '이서연', family '김민준', as composed. Jamo that compose to no syllable are hangul to every rule (`ᄒᆞᆫ 김` → family 'ᄒᆞᆫ', initials ''), the two fillers U+115F and U+1160 with them; the compatibility jamo stay out — 2026-11-05 #1087.
- A closed-list shape test is asked of the NFC-composed word too: `_vocab.is_patronymic_marker` composes a non-ASCII word before the `_TURKIC` patterns, and `locales/tr_az.py`'s `DEVIATES` composes the name — 2026-11-10 #1316.

Not standing: the KNOWN LIMITS of the undated bullet under 2026-10-12 #652 (the decomposed initial and the decomposed `й`), closed by 2026-10-13 #665.

Open: none in this file.

Output keeps the encoding written; only the reading is made encoding-independent. - 2026-11-05 #1087 — HANGUL IN THE SCRIPT TABLE HOLDS THE CONJOINING JAMO. `_policy._SCRIPT_RANGES` held the precomposed syllables alone, while `_locale._letter_runs` decided "CJK" by character name and counted the jamo; the two definitions disagreed, and moving `_letter_runs` onto the table first would have taken the two-family-names declaration away from decomposed `김. 민준` (#1083's refused candidate). DECIDED: HANGUL is the syllables plus all three conjoining jamo blocks, U+1100–11FF, Extended-A U+A960–A97F and Extended-B U+D7B0–D7FF. The extended blocks hold only archaic jamo, and the table leaves out the archaic kana on that ground, but the U+1100 block carries archaic jamo too, so a modern-only line cannot be drawn at block granularity, and the three are what Unicode composes a syllable from. The compatibility jamo U+3131–318E compose nothing and stay out, rules/R7's `ㄱㄴ 김` initialling `ㄱ.` as before. WHAT IT MOVES, measured 2026-11-05 against the same tree with the old table: the readers that classify a token compose it first (`_vocab._normalized_for_script`, the #665 veto, `_render`'s initials), so modern jamo were already hangul to them, and decomposed `김 민준`, `김. 민준` and `민준 김` already read family-first under rules/W4 (decomposed `민준 김` reads family '민준', given '김', and its composed twin family '민', given '준', middle '김', since only the composed 민준 divides).
