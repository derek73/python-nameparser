# H10 — a title written as a run of letters

## Standing

- A run of single letters joined by full stops whose spelling without them is a title written `dotted` (`us`, `uk`, German `pd`, compiled into the private `DOTTED_TITLES`) reads as that title in a title run at the head of a name, the given part's or the part before a family comma, where a title the run keeps stands behind it after H3's floor has given its word back (`U.S. District Judge Marc Thomas Treadwell` → title 'U.S. District Judge'); otherwise it is the initials it is written as (`U.S. Grant`, `Hon. U.S. Grant`, `U.S. Senator Jr`, `U.S. Grant Smith, John`) — 2026-11-09 #490, DECIDED.
- Where the comma's decision reports paired initials opening the part after it (rules/C11), the report stands on a run this rule reads as the title (`Smith, U.S. Senator John`) — 2026-11-09 #490.
- Only the titles that abbreviate several words are marked, so initials spelling a title of one word stay a name with a title word behind them (`D.R. Judge Smith` → given names 'D.R. Judge' (rules/T7 parting the run)); the cost kept is a person whose initials spell a marked title and whose next name is a title word (`P.D. Judge Smith` → title 'P.D. Judge') — 2026-11-09 #490, DECIDED.

- 2026-11-09 #490, decided in chat — A RUN OF SINGLE LETTERS SPELLING A TITLE MARKED `dotted` IS THAT TITLE WHERE A TITLE FOLLOWS IT. `U.S. District Judge Marc Thomas Treadwell` read given 'U.S.', middle 'District Judge Marc Thomas', while `US District Judge …` read title 'US District Judge', because a title is looked up with its interior stops kept (`u.s`) where a suffix acronym is looked up with them removed (`M.D.` → `md`). 1.4.0 reads the same as master (wheel checked 2026-11-09), and the 1.x suite held the case as an xfail citing #490.
  WHY NOT EVERY TITLE. #490's 2026-10-02 comment recorded why the interim 2.0 build that stripped every stop was reverted: 73 two- and three-letter titles collide with ordinary initial pairs (`D.R.`, `M.R.`, `M.S.`, `S.T.`, `H.R.`), and `U.S. Grant` would lose its given name.   THE VOCABULARY. A behavioral title property, `dotted = true`, compiles into `DOTTED_TITLES` and the private `Lexicon._sets.dotted_titles`; a caller writes it with `add(w, kind=..., dotted=True)`. Marked: `us` and `uk` (en.toml, modifiers) and `pd` (de.toml, Privatdozent), each an abbreviation of several words. Left unmarked: `ceo` and `cfo`, abbreviations of several words that no corpus row writes before another title, which a caller may mark; every abbreviation of one word (`dr`, `mr`, `lt`, `col`), since nobody writes a stop between its letters and its dotted spelling is always initials; and the military ranks the issue listed (`bg`, `mg`, `pfc`), which no corpus row writes dotted.
  THE MECHANISM. classify tags the run (`vocab:dotted-title`) where its folded spelling without stops is in the set and its text is a run of two or more single letters joined by stops, the last stop optional (`_vocab.is_dotted_title`). `_pieces.leading_titles`, the given part's leading run, counts a tagged piece as a title word, applies H3's floor, then gives back a tagged piece the run ends on, and asks the one before it again (`Hon. U.S. Grant` keeps title 'Hon.'). H6's run before a family comma, which reads by vocabulary only, does the same, so `U.S. Senator Smith, John` reads as `US Senator Smith, John` does; it now counts its run before setting roles. The run is read as the title it spells by the other readers of the head too: by H9's phrase test, so a gated title behind it has its partner (`U.S. Marshal John Smith` reads as `US Marshal John Smith`), and by C4's count of name words before a comma, which counts it as a title only where it opens the part (behind any titles) and a title, listed or by H2's shape, follows it with a word behind (a word of any kind, so `U.S. Senator Jr., Ed` counts it, and the floor then gives 'Senator' back and the run after it, reading as master did), so `U.S. Senator Smith, Ed` keeps given 'Ed' as its undotted twin does (both found by the code review: the first build read `U.S. Marshal` as given 'U.S.' and `U.S. Senator Smith, Ed` as title 'U.S. Senator', suffix 'Ed', no given name). A run a connective joins to another (`U.S. and U.K. Ambassador`) is one unit of several words and stays a name, an accepted gap. H9's phrase test reads the run as the modifier it spells wherever it stands, as it reads the undotted twin, so `John Smith U.S. Dean.` reads title 'Dean.', family 'U.S.' as `John Smith US Dean.` does (master and 1.4.0 read family 'Dean.'), the run then reporting `suffix-or-name` as rules/S3's unlisted dotted shape ending the name, which its undotted twin cannot raise, and `U.S. Vice Smith`, two modifiers with no head, keeps given 'U.S.' (both found by the review of the fix commit; accepted as the twin's reading, rules/H10's Accepted clause). The fold runs only where the name holds a word H9 reads, so a name with a run and no such word (`U.S. Grant`) pays no phrase test for it. Where the count reads the run as a title and H6 then gives it back (`U.S. Insp. Smith, Ed`, H6 reading by vocabulary only, and `U.S. St. Smith, Ed`, a title-particle stopping H6's run), the comma decision is the one the undotted twin makes and the run lands in the family, as H10 reads it with no title kept behind it. The run is read as a title only at the head of a part: at the end of a name H5's chain takes neither the run nor its spelling without stops (`John Smith US Senator` keeps family 'Senator').
