# H1 — a title and one name word

## Standing

- What stands beside the one name word decides nothing: a suffix, a nickname or a maiden name leaves a title's family reading in place (`Dr. Smith née Jones` → family 'Smith', `'Smitty' Dr. Jones` → family 'Jones') — 2026-08-25 #410.
- The guard tests which roles are unoccupied and counts no units, a gap recorded and not fixed: a given run of two name units moves whole (`Freiherr de V Jr` → family 'de V') — 2026-08-25 #410.
- A title run addresses as its last title does, its key matched whole or by its last word through the one predicate H1 and P5's licence share: `Her Majesty Queen Elizabeth` and `Mr Sir John` read given 'Elizabeth' and 'John' — 2026-09-08 #489.
- Where a run stands before the one name word, that run addresses; a run behind the word decides its field only when none stands before, and a run written around a nickname is one run: `Sir John Prof.` → given 'John', `Dr. Smith Sir.` → family 'Smith', `Smith Sir.` → given 'Smith', `Dr. 'Smitty' Sir John` → given 'John' — 2026-09-08 #489; 2026-09-09 #316.
- `prince` and `princess` are given-name titles and `lord` and `lady` are not, decided rather than deferred, since the text does not say which rank a bearer holds: `Prince Harry` → given 'Harry', `Lord Byron` → family 'Byron', `His Excellency Lord Duncan` → family 'Duncan' — 2026-09-10 #519.
- H1 decides the field of the one name word before a comma with no given name after it, and of the one name word of a name read family-first: `Elizabeth II, Queen` → given 'Elizabeth', `Smith, Sir` → given 'Smith' with the family empty, `Sir John` and `Pope Francis` given under every order — 2026-10-18 #720.
- A particle surname keeps the family where something settled it, a comma (`van der Berg, Sir`, `Van, Sir`) or P1's fold asked of the leading name piece (`Sir de Mesnil`); an ambiguous particle no comma settled reads given (`Sheik Abu Bakar`, `Sir Van` family-first), and so does a never-given one the fold does not take (`St Sir de Mesnil` under every order) — 2026-10-18 #720.

Elsewhere: the graf class, a title word borne as a name but rarely as its first word shipping as a title (`Greve Anna` → title 'Greve', family 'Anna'), is decisions/salutation-titles' 2026-10-04 #606 bundle; the renunciate fold, a given-name title before one name word (`Swami Vivekananda` → given 'Vivekananda'), is decisions/indic-honorifics' 2026-09-06 #346/#344/#343 bundle.

Open: [#348](https://github.com/derek73/python-nameparser/issues/348) (whether a word that is both a title and a given name reports an ambiguity; `Prince Fielder` reads given 'Fielder').
