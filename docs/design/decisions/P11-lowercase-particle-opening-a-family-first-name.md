# P11 — a lowercase particle opening a family-first name

## Standing

- Under a family-first order an ambiguous particle opening the name, written in lower case in a name of mixed case, is folded as a never-given one is (`van den Berg Cornelia` family-first → family 'van den Berg', given 'Cornelia'), under both family-first orders, and reports nothing; a capitalized one, or one in a name of one case, keeps its positional reading and its report (`Le Van Thanh` family-first → family 'Le') — 2026-11-04 (Derek), #670.
- The default order is out of the rule's reach: `van Gogh` still reads given 'van', family 'Gogh', and reports — 2026-11-04 (Derek), #670.

Open: none in this file.
