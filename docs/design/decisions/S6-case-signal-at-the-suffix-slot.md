# S6 — the case signal at the suffix slot

## Standing

- In a name written in more than one case, a member of `suffix_acronyms_ambiguous` written in capitals leans credential and is taken with nothing to spare (`Jack MA` → suffix 'MA'), and one in any other cased form that is not wholly lower leans surname (`John Smith Ma` → family 'Ma'); an all-lower member, or a name written in one case, takes the positional count (`JOHN SMITH MA`, `john smith ma` → suffix) — 2026-09-14 #289.
- The case fact counts the judged word itself, so `JOHN SMITH Ma` is mixed case and `Ma` leans surname. Whether a cased suffix counts as case evidence is answered for render only (decisions/R5); the parse keeps counting it — 2026-09-14 #289; 2026-09-23 #492.
- At the first slot after a comma the count goes first, of name words, and the lean is read only where the count leaves the word a name: `Smith, MA` → suffix, `Smith, Ma` and `Smith, ma` → given, `Smith Jr., MA` → suffix 'Jr., MA' — 2026-09-14 (Derek); 2026-10-20 #761.
- A caseless script carries no lean, and the name-word count still reaches it: `마틴 킹, MA` → suffix 'MA', `毛泽东, MA` → given 'MA' — 2026-09-17.
- The one-case fact is computed over the name's own words by one shared helper (`_pieces.own_words`), which classify always calls and every other stage that reads the fact calls rather than copying it — 2026-09-14, corrected.
- `Freiherr von Berg MA` reads family 'von Berg', suffix 'MA', the lean ending P2's chain with no words to spare — 2026-09-15 (Derek).
- The whole-PR review's five readings stand: an acronym the particle chain absorbs reports `suffix-or-name` (`John van der Berg Ma`); the CJK stage asks the post-comma run with the one-case fact; a by-shape credential in a tail segment raises no `comma-structure`; a word a caller lists as a surname is never caps-shaped; and a dotted listed member takes the lean — 2026-09-18, WHOLE-PR REVIEW ROUND.

- A listed member of `suffix_acronyms_ambiguous` written in capitals in a name of mixed case is settled as the credential by its writing and reports nothing at any slot that reads it (`John Smith MA`, `Jack MA` but its `given-or-family`, `John Smith, MA`, `Doe, John DO`), and it starts the credential's trailing run (rules/S8: `John Smith MA Jones` → suffix 'MA Jones'); the clash settled is the one with the name reading alone, so the word keeps its tags and its other readings (`Doe, John DO` keeps family 'Doe'), a maiden clause still keeps it as its first word and reports it (`Jane Doe nee MA`), and nothing before a comma leaves it the given name, reported (`, MA Smith`) — 2026-10-25 #785 (Derek, 2026-10-23); 2026-10-25 #785, review.

- 2026-09-14 #289 + #516 (this PR) — A BARE AMBIGUOUS ACRONYM IS READ BY THE EVIDENCE THE WRITING CARRIES, and written case is evidence the words-to-spare count does not have. In a name written in more than one case, a member of `suffix_acronyms_ambiguous` written in CAPITALS leans credential and is taken as a suffix with nothing to spare (`Jack MA` → given 'Jack', suffix 'MA', as `Jack MD` has always read); one written in any other cased form that is not wholly lower leans SURNAME and stays a name word with plenty to spare (`John Smith Ma` → middle 'Smith', family 'Ma'). An all-lower member carries no lean, a name written wholly in one case carries none at all, and both take the positional rule unchanged — `JOHN SMITH MA` suffix, `ANH DO` family, `john smith ma` suffix. Switch-free and scoped to the listed set: `ba do ed jd ma`.
  THE PREDICATE KEEPS THE JUDGED TOKEN IN THE SPAN, and that is what gives the right answers here. `JOHN SMITH Ma` is MIXED because of `Ma`, and a Title-case word against all-caps neighbours is exactly the surname signal this design wants; excluding the judged token would make the name one-case and hand `Ma` to the positional rule. Same for `Jack MA` read the other way — included, the name is mixed and the capitals lean credential; excluded, `own == ['Jack']` is one case and the peel keeps the family. The general question — whether a cased suffix token counts as case evidence — is #492's and stays deferred; this entry records that the INCLUDING reading is what this design rests on.
