# T7 — a given name written as a run of initials

## Standing

- A given name written as a run of single letters joined by full stops, in capitals or in a name written wholly in lower case, with a family beside it or a family comma, parts into one initial per letter once roles are final: the letter in the given name's place in the order is the given name and the others are middle names (`E.T. Smith` → given 'E.', middle 'T.'); `initials()` gives one initial per letter of any such run left whole — 2026-11-10 #1296.
- A run in lower case among capitals, one the vocabulary lists with its full stops or a case mask writes as a word of its own (keyed with its stops and writing a lower-case letter, or writing a stop), in another field, with no family, or under `middle_as_family` or `two_given_names` keeps its one word — 2026-11-10 #1296.
- With a nickname, `str()` lays the parted letters out as written apart (`E.T. "Bob" Smith` → 'E. "Bob" T. Smith'), accepted — 2026-11-10 #1296.

Elsewhere: that a run of single letters stays one word while the name is read, so rules/S3 still sees `John Smith E.T.` as one dotted word, is decisions/period-joined-words' 2026-11-09 #1255 entry.

Open: none in this file.
