# S3 — credentials written with interior periods

## Standing

- A dotted token loses its chunk claim only where every chunk the vocabulary matches is a single ASCII character (`i`, `v`, `2`): `John Smith R.A.I.` then reads suffix 'R.A.I.' by shape, with a report, and `Jack X.Y.I.` keeps family 'X.Y.I.', while `Msc.Ed.`, `JD.CPA`, `Lt.Gov.` and `J.씨` keep their chunk readings; retiring every chunk match was declined — 2026-09-15.
- A digit-dotted token (`1.4.2`) loses the chunk claim and is no member of the shape class either, so it reads as a name word, silently (`John Smith 1.4.2` → family '1.4.2') — 2026-09-18.
- An ambiguous acronym written with its periods, one after each letter or one after each of two or more letter chunks, counts as unambiguous, and a single trailing period does not (`Jack M.A.` → suffix, `Jack Ma.` → family); the clause stood in rules/S2 until it moved here — 2026-10-19.
- Paired initials of a script with capitals (two single letters each followed by a period, the second optional) are no word of the ambiguous class at the trailing slots and read as the name word they are written as, reported, as the switch off reads them: `Ram Bahadur B.K.` → middle 'Bahadur', family 'B.K.'; `Bahadur, Ram B.K.` → middle 'B.K.'; `Ram Bahadur B.K., PhD` → family 'B.K.', suffix 'PhD'. At the first slot after a comma they stay C5's (`John Smith, X.Y. P.Q.` → suffix), behind a suffix word they join the run (`Ram Bahadur PhD B.K.` → suffix 'PhD B.K.'), and three dotted letters, longer chunks and a caseless script's pair keep the position reading (`John Smith X.Y.Z.`, `John Smith B.Tech.`, `สมชาย ใจดี พ.บ.` → suffix) — 2026-10-24 #864.
