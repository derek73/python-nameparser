# O8 — letters ending a name as its family

## Standing

- The default reading of letters ending a name does not change: `Lakshmi R S` keeps middle `R`, family `S` — 2026-11-11 #1254.
- Reading the letters as the family is an opt-in `Policy` switch, `initials_as_family`, off by default, which a pack's `[rules]` may turn on (`initials_as_family = true`): given-first, it is the same string shape as a middle and a family initial and as a byline written surname first — 2026-11-11 #1254.
- The switch reads two or more letters in a row, each in the shape rules/T5 reads as an initial, ending the name words, under the given-first order, with no family comma and a name word before them; one letter, letters before or inside the name and a name read family-first are left as they are — 2026-11-11 #1254.
- No byline value: `name_order=FAMILY_FIRST` stays the setting for a bibliography written surname first, since no list's own names can select such a value safely — 2026-11-11 #1254.
- `locales.NE` turns the switch on; no other pack does — 2026-11-11 #1254.
- The switch reports nothing — 2026-11-11 #1254.

## Log

- **2026-11-11 #1254 — LETTERS ENDING A NAME ARE ITS FAMILY ONLY WHERE THE CALLER, A PACK OR THE GROUP SUGGESTER SAYS SO.** #1163 asked whether `Lakshmi R S` should read family `R S` by default, citing 538 ORCID records whose family box held the letters against 0 holding the word before them. That count could not decide it: ORCID's `name` field is composed as the given box then the family box (`tools/differential/local_orcid.py`), so the word before the letters can never be the family there; the count reproduces from that field, 539 to 0 on the 2026-10-27 fetch (`repro_1163.py`). Measured instead on text the writer typed whole, with throwaway scripts against the local corpora, on master 5a072056 (fetched: orcid-researchers 2026-10-27, ctgov-officials 2026-10-21, nepal-candidates 2026-10-24, tse-donors 2026-10-22, opensanctions-parliaments 2026-11-08, patentsview-inventors 2026-10-28). The scripts (`repro_1163.py`, `composed_lw.py`, `orcid_net.py`, `nepal_recount.py`, `sansad_recount.py`) are in the 3.1 cycle's session notes, not the repository, so these counts cannot be re-run from the tree; they are dated snapshots. A name ending in a spaced run of two or more letters falls in one of three classes: the letters are the family (the switch fixes it), a middle and a family initial (`Melanie J D`, the switch breaks it), or a byline whose first word is the family (wrong either way).
