The 2026-08-31 entry's numbers were measured that date, on py3.11 wherever no other interpreter stands beside them (this said "every number below is a py3.11 measurement of 2026-08-31" until 2026-10-22, when that entry and later ones had long quoted other interpreters and dates), recomputable with `uv run python tools/perf/call_count.py` (add `--modules`, `--stages`, or `--against <ref>`).
