# deviates-registry — packs stay pure data (option C)

## Standing

- A locale pack declares its deviations from the defaults as a module-level `DEVIATES` callable, acceptance metadata kept off `Locale`, whose value equality and pickling a callable field would break; `test_registry_is_the_pack_contract` fails unless every registered policy or segmentation pack ships `DEVIATES`, and every registered pack a rotator list, which is what lets mechanisms.md#LOCALE-PACKS-PURE-DATA promise packs no code paths of their own. A field on `Locale` is to be revisited only if a runtime consumer of the declaration, such as an `explain()`, appears, and none has — 2026-07-18. A vocabulary pack's deviations are derivable instead, from the reading index (`_reading_index.changed_words`), which tests/v2/test_locales.py's choice gate reads; the gate ors the derived surface into every registered pack with `languages`, so a hand `DEVIATES` declares only what a fragment or a patch beside a choice changes; the contract test refuses a `DEVIATES` on a pack that is nothing but a choice of languages (`locales.NE`, the first, and `SL` and `HR`), and a choice pack whose choice changes no word, and requires one of every other pack, `CS` and `SK` among them since their patch — 2026-10-29 #753, phase 3b; 2026-10-30 #753, phase 3d; 2026-10-30 #753, phase 3f; 2026-10-30 #753, phase 3f amended.

## Log

- 2026-07-18 (d4aaafa; the DEVIATES design note) — a `deviates` field ON Locale was rejected: callables break value equality and pickle-by-reference, and DEVIATES is acceptance metadata, not runtime behavior (revisit only if a runtime consumer like explain() appears). The REGISTRY became the contract instead: test_registry_is_the_pack_contract fails structurally unless every registered pack ships DEVIATES and its rotator list. This is why LOCALE-PACKS-PURE-DATA can promise "no code paths of their own" and mean it.
- 2026-10-29 #753, phase 3b — A VOCABULARY PACK'S DEVIATIONS ARE DERIVED, NOT DECLARED. `Locale.languages` selects among the default's readings, so the words a choice can move are computable: `_reading_index.changed_words(chosen)` is every word joining or leaving a compiled constant under the choice, and tests/v2/test_locales.py's `test_non_interference_each_choice` requires the default's reading for every corpus name holding none of them, with a negative control (`test_the_choice_gate_fails_when_its_surface_misses_a_word`). No pack ships in 3b, so the gate runs over choices of the files' tags; the registry contract test still asks every REGISTERED pack for `DEVIATES` and a rotator list, and learns to read a derived surface for a pack with `languages` in the PR that registers the first one (3d). The policy and segmentation packs (JA, RU, TR_AZ, ZH) keep theirs, decisions/vocabulary-model's 2026-10-27 #753 entry, item 7.
- 2026-10-30 #753, phase 3d — THE CONTRACT READS A DERIVED SURFACE. `locales.NE` registers the first pack whose content is a choice of languages and nothing else (`Locale.lexicon` empty, `Locale.policy` the empty patch). tests/v2/test_locales.py's `_deviates(code)` gives the gate, the rotator test and the combined gate every pack's predicate: the surface derived from its `languages` through `changed_words` and the 3b choice gate's `_surface_deviates`, or'd with its `DEVIATES`, so a pack with a fragment or a patch beside a choice needs to declare only that part (`test_a_pack_with_a_choice_and_a_patch_declares_only_the_patch`; nothing refuses a hand copy of the choice's words there); `test_registry_is_the_pack_contract` refuses a `DEVIATES` on a pack that is nothing but its choice, so a hand copy cannot drift beside the derived one, and still requires one of every other pack. Its rotator list stays required, as the gate's positive side. decisions/vocabulary-model's 2026-10-30 phase 3d entry, item 2.
- 2026-10-30 #753, phase 3f — A CHOICE PACK MUST CHANGE A WORD. `locales.CS`, `SK`, `SL` and `HR` register as choice packs under phase 3d's contract, with no `DEVIATES`. `test_registry_is_the_pack_contract` adds one refusal: a choice pack whose choice changes no word (an empty `changed_words`), since its gate would pass on nothing; and `test_choice_rotators_cover_every_changed_word` holds each choice pack's rotator list to a name per changed word, so the gate's positive side reaches every word. The combined gate reads the surface of the union of every registered pack's languages, since `parser_for` applies one choice, not one per pack, or'd with every pack's hand `DEVIATES` whatever the pack, since a mixed pack carries both. decisions/vocabulary-model's 2026-10-30 phase 3f entry.
- 2026-10-30 #753, phase 3f amended — A CHOICE PACK THAT GAINS A PATCH DECLARES THE PATCH'S PART, AND THE PACKS SHARING A PATCH SHARE ONE DECLARATION. `locales.CS` and `locales.SK` gain rules/O6's patch (`two_family_names`), so they leave the choice packs and ship `DEVIATES`, as `locales.ES` does, the contract test requiring it of every pack that is not a choice alone. Their declaration is the one `ES` already made for the same patch: three or more name words, or three or more runs of letters. It moved from `locales/es.py` into `_locale.deviates_by_two_family_names`, which all three packs' `DEVIATES` return, so the three cannot drift apart (`test_cs_and_sk_pack_contents` holds them to it). Each pack's title and generation rotators are names the patch alone leaves as the default reads them (`MUDr Novák`, `Novák PhDr.`, `Jana Nováková (roz. Svobodová)`), since `test_a_choice_word_rotator_is_moved_by_the_choice_alone` refuses one the patch moves; the patch has rotators of its own. decisions/vocabulary-model's entry of this date.
- 2026-11-05 #1087 — THE TWO-FAMILY-NAMES DECLARATION COUNTS BY THE SCRIPT TABLE. `_locale._letter_runs` counted a run twice when its first character's Unicode name began `CJK`, `HANGUL`, `HIRAGANA` or `KATAKANA`, a second definition of East Asian text beside `_policy._SCRIPT_RANGES`, which every script-conditional rule reads. It now asks `_script_matcher` over the table, so a run W1 can divide is one the declaration counts twice. Moved first, before the table held the conjoining jamo, the declaration would have dropped decomposed `김. 민준` (#1083's refused candidate, which measured 4 of 6,731 names moving); with HANGUL widened (decisions/nfd-shapes, same date), 3 of the 6,738 distinct corpus texts moved (measured 2026-11-05, every distinct name `tools/differential/snapshot.py` reads, the comparator the character-name test run beside the table in one script), each gaining a declaration, the safe direction: `ﾔﾏﾀﾞ ﾀﾛｳ`, `ﾀﾅｶ. John` and `ﾀﾛｳ·ﾔﾏﾀﾞ`, halfwidth katakana the name test did not count. None lost one. Over all of Unicode (version 14, Python 3.11), the letters the name test counted and the table does not are the compatibility jamo, the katakana phonetic extensions, and the supplementary plane's Minnan tone kana and archaic and small kana, which no rule classifies and W1 never divides, so a run of them counts once correctly; the table adds 々, 〆 and the halfwidth katakana. `test_the_two_family_names_declaration_counts_by_the_script_table` in tests/v2/test_locales.py holds the rows with both former definitions' answers as recorded controls.
- 2026-11-12 #1237 — A CHOICE THAT CHANGES NO WORD, BESIDE A PATCH, IS RECORDED AS INERT. `locales.MN` chooses `mn`, whose readings are all on by default, beside a Cyrillic script order its patch carries in code (decisions/W4's 2026-11-12 #1237 entry), so its derived surface is empty. The phase 3f refusal is unchanged, since it reads only a pack that is nothing but its choice, and MN declares `DEVIATES` for its patch, which the gate reads; `test_choice_rotators_cover_every_changed_word` and `test_a_choice_word_rotator_is_moved_by_the_choice_alone` skip a pack listed in tests/v2/test_locales.py's `_INERT_CHOICES`, and `test_an_inert_choice_changes_no_word` fails the day such a choice changes a word, so the pack leaves the set and its rotators name the word. decisions/vocabulary-model's 2026-11-12 #1237 entry.
