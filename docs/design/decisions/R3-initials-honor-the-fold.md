# R3 — initials honor the fold

## Standing

- Each group initials in the order its field reads: written order, except folded family words (O3's fold, P6's attachment), which initial first as they render first (`Hassan, Mohamad Ahmad Ali` under `middle_as_family` → 'M. A. A. H.', `der, y van` → 'y. v. d.'), which brought the `middle_as_family` orders back to 1.4.0's (`Doe, Dr. John A.` → 'J. A. D.') — 2026-08-30 #408.
- The fold partition applies to every role the view renders, though only the family can carry the tag today, pinned from a hand-built name with two tokens per role; P6's half has no rules/R3 example line, its one witness `der, y van` having a contested parse, and is pinned in a unit test — 2026-08-30 #408.
- A connective contributes nothing where it is joining, a part holding another name word for it to join, the part's working particles set aside, and initials like any name word where its part holds nothing else; one rule for every group, asked of the whole part and never by a word count (`John and Jane Smith` → 'J. J. S.', `Juan y Garcia` → 'J. y. G.', `Juan Velasquez y Garcia` → 'J. V. G.', `Jon Dough and` → 'J. D.', `Juan de y` → 'J. y.') — 2026-09-20 #461.
- The fact is decided once per part and recorded on the token as UNJOINED_CONJUNCTION_TAG, a marker separate from UNJOINED_TAG so `family_base`, `family_particles` and case repair do not move; the core view and the facade both read it, and `Parser.revise` recomputes both marks (`revise(n, family='de y')` → 'J. y.' for `Juan Smith`) — 2026-09-20 #461.
- The given group's answer is a deliberate 1.4.0 parity break (1.4.0 'J a J. S.' for `John and Jane Smith`), and a lone connective's initial restores 1.4.0's own answer (`JUAN Y GARCIA` → 'J. Y. G.', `محمد و علي` → 'م. و. ع.') — 2026-09-20 #461.

W.', `john e smith` → 'j. e. s.'); a token carrying `UNCLASSIFIED_TAG` falls back to the vocabulary through `_render._reads_as_conjunction`, the helper case repair calls, and the particle question stays `_is_particle`'s live vocabulary lookup — 2026-09-01 #462; 2026-09-13 #528.

- An initial is the shortest start of its word that composes to the composed word's first character, written in the form the writer used (`émile zola` typed decomposed → 'é. z.' decomposed, decomposed `マイケル ジャクソン` → 'マ. ジ.'), a first code point excluded from composition kept as written (`ज़ाकिर` with U+095B → 'ज़.'); composing the initial to NFC and taking the first letter with its following marks were declined — 2026-10-02 #585.
